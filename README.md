# 📱 Praktikum Mobile Programming 1

Repositori ini berisi kumpulan tugas dan latihan selama mengikuti mata kuliah **Mobile Programming 1** pada semester 4. Praktikum dilakukan menggunakan **Kotlin** dengan **Android Studio**, mencakup dasar-dasar pengembangan aplikasi Android seperti UI dasar, navigasi antar activity, intent, fragment, dan penggunaan komponen penting lainnya.

---

## 🧠 Materi yang Dicakup

| Minggu | Materi                                 | Folder                          |
|--------|----------------------------------------|---------------------------------|
| 1      | Pengenalan Android Studio & Kotlin     | `HelloWorld`                    |
| 2      | Activity dan Intent                    | `IntentActivity`                |
| 3      | Layout dan ConstraintLayout            | `LayoutExample`                 |
| 4      | RecyclerView dan Adapter               | `RecyclerViewApp`               |
| 5      | Fragment dan Bottom Navigation         | `FragmentNavigation`            |
| 6      | Implicit Intent dan WebView            | `ImplicitIntentApp`             |
| 7      | Form Input dan Validasi                | `FormValidation`                |
| 8      | SharedPreferences                      | `SharedPrefExample`             |
| 9      | SQLite dan Room Database               | `LocalDatabaseApp`              |
| 10     | Ujian Tengah Praktikum (UTP)           | `UTPProject`                    |
| 11-14  | Final Project & Presentasi             | `FinalProject`                  |
